## 各题摘要

### A. 回忆 —— 栈重建 [题解](A/solution.md) · [代码](A/sol.cpp)

给定压入记录与 T/F 查询结果，弹栈操作全部丢失。要求插回若干弹栈操作，使得过程中栈内元素互不重复、所有查询结果与记录一致，输出由 `+` / `-` / `?` 组成的合法操作串。

- 核心：从右往左预处理每个元素"最晚必须离开"（下一次压入或 F 查询）与"最后一次必须存活"（最后一次 T 查询）两个边界，再从左往右贪心模拟真实栈，必要时安全清理与强制弹出。
- 复杂度：O(n log n) 时间，O(n) 空间。

### C. 排列逆序对 [题解](C/solution.md) · [代码](C/sol.cpp)

给定 m 条情报，每条给出区间 `[l, r]` 内位置的完整大小顺序（一条链），构造满足所有情报且**逆序对最少**的 1..n 排列；情报矛盾输出 -1。

- 核心：相邻约束建边得到偏序图，有环即无解；Kahn 拓扑排序时用**最小堆**每次取下标最小的可填位置。贪心正确性依赖"每条情报把整个区间串成一条链"的结构。
- 注意：样例第 1 组按题面规则并不矛盾（题解有详细论证），本解法输出 `1 3 2 4`；第 2、3、4 组与给定答案逐字节一致。
- 复杂度：O((∑n + ∑E) log n)，支持 T ≤ 1e6 组、∑n ≤ 1e6。

### D. Sequence —— 01 串计数 [题解](D/solution.md) · [代码](D/sol.cpp)

给定所有 `p_i`（第 i 个字符之前与它不同的字符个数）组成的多重集，求能产生该多重集的 01 串数量，对 998244353 取模。

- 核心：利用 `sum(p) = a·b`（a、b 为两类字符个数）枚举较小类数量；贪心按计数数组顺序处理，两类数量相等时产生因子 2。
- 复杂度：O(n) 时间，O(n) 空间。

### L. Longest Common Prefix [题解](L/solution.md) · [代码](L/sol.cpp)

依次读入 n 个小写字符串，每读入一个就输出 `Σ(f_j XOR j)`，其中 `f_j` = 恰好挑 j 个串时的最大 LCP 长度。

- 核心：建 trie，`cnt[u]` = 经过节点 u 的串数，`f_j` = 所有 `cnt ≥ j` 节点的最大深度；插入一个串时只有 `j = cnt` 这一个位置的 f 会变化，做单点更新并用增量维护答案。
- 复杂度：O(Σ|s| + n) 时间；trie 空间约 52 MB。
